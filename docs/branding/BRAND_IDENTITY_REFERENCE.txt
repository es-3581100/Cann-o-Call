# Cann-o-Call — Brand Identity Reference

Status: Canonical visual/text reference derived from the approved brand source image.
Purpose: Preserve a consistent visual identity across application UI, icons,
documentation, repositories, marketing images, and generated supporting assets.

---

## 1. Brand Name

Cann-o-Call

Primary descriptor:
ACTOR RUNTIME

---

## 2. Brand Essence

Cann-o-Call is an actor-driven agent-runtime that orchestrates:

- autonomous agents
- state flows
- secure communications

Core statement:

Every call.
Every actor.
Every state.
Connected.

The brand should communicate a system in which independent actors exchange
messages through a reliable runtime while observable state moves through the
system.

---

## 3. Brand Personality

Primary traits:

- RELIABLE
- AUTONOMOUS
- TRANSPARENT
- MODULAR
- SECURE
- RETRO-FUTURISTIC

The product should feel technical and capable without becoming visually
chaotic.

It should communicate:

- observable machinery
- explicit state
- discrete actors
- message passing
- controlled coordination
- trustworthy runtime infrastructure

---

## 4. Tagline

END TO END STATE SYSTEM

EVERY CALL - EVERY ACTOR - EVERY STATE

---

## 5. Brand Mission

To provide a transparent, reliable, and extensible runtime for autonomous
agents to communicate, collaborate, and evolve — securely, at scale.

---

## 6. Primary Visual Motif

The central brand mark is a luminous geometric diamond/core.

Visual characteristics:

- diamond-shaped outer silhouette
- bright white/cyan center
- turquoise inner glow
- electric-blue outer geometry
- dark navy/black surrounding field
- pixel-art / digital-rendered construction
- luminous, energized appearance

Conceptually, the mark can represent:

- runtime core
- state
- active message
- actor identity
- system coordination
- connected execution

The diamond/core should remain the most recognizable reusable symbol in the
brand.

---

## 7. Logo System

### Primary Logo

Diamond/core icon + "Cann-o-Call" wordmark + "ACTOR RUNTIME" descriptor.

Preferred presentation:
- full color
- dark background
- cyan/blue illumination
- white/light primary wordmark

### Square Mark / Avatar

Use the diamond/core icon by itself inside a dark technical frame.

Suitable for:

- application icon
- avatar
- favicon
- small repository identity
- actor/runtime badge

### Horizontal Mark

Diamond/core icon followed by:

Cann-o-Call
ACTOR RUNTIME

Use where horizontal space is available.

### Brand Usage Rule

Use the full-color logo primarily on dark backgrounds.

Maintain clear space around the mark approximately equal to the height of the
central diamond icon.

Do not:

- stretch the logo
- distort its proportions
- arbitrarily recolor it
- remove essential geometry
- place it on visually noisy backgrounds that destroy contrast

## 11. Illustration Style

Primary illustration direction:

RETRO-FUTURISTIC PIXEL TECHNOLOGY

Combine:

- pixel-art influence
- dark sci-fi control surfaces
- modern technical dashboards
- cyan/blue emissive lighting

---

## 12. Actor Visual Language

Actors are represented as small autonomous robotic entities.

Actor characteristics:

- compact
- friendly but mechanical
- visibly separate from the central runtime
- cyan/blue illuminated accents
- capable of independent activity
- visually connected through messages/state flows

Actors should appear like workers participating in a larger deterministic
system rather than human-like AI characters.

---

## 13. Runtime Visual Language

The runtime is the central coordinating machine.

Represent it using:

- central mechanical core
- diamond/state mark
- message connections
- data conduits
- event flow
- server/state-store relationships
- visible input/output pathways

The system should visually communicate:

ACTORS -> MESSAGES -> RUNTIME -> STATE / EVENTS

rather than presenting the runtime as a mysterious AI black box.

---

- generic glassmorphism

Appearance:
- luminous blue/cyan
- technical border
- high contrast

- blue-gray border

## 22. Builder Guidance

When creating new Cann-o-Call UI or media:

1. Start with the dark navy foundation.
2. Use cyan as the dominant identity accent.
3. Reserve yellow/red for meaningful state.
4. Prefer technical geometry over soft decorative shapes.
5. Use the diamond runtime mark as the recurring identity anchor.
6. Represent agents as discrete actors.
7. Represent communication explicitly with messages/links.
8. Represent state visibly.
9. Keep system mechanics understandable.
10. Preserve the retro-futuristic pixel-tech character.
11. Favor observable infrastructure over AI-themed abstraction.
12. Keep new visuals recognizably part of the same Cann-o-Call system.

## Canonical Brand Summary

Cann-o-Call is a dark, retro-futuristic actor-runtime brand centered around a
luminous cyan diamond/core.

Its visual language combines pixel-inspired machine imagery, autonomous robot
actors, explicit message/state flows, dark technical dashboards, monospaced
system information, and cyan/blue illuminated infrastructure.

The identity should consistently reinforce one central idea:

EVERY CALL.
EVERY ACTOR.
EVERY STATE.
CONNECTED.
