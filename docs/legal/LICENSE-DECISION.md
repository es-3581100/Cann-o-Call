# Cann-o-Call License Decision

**Decision status:** `FINALIZED`
**Selected model:** Business Source License 1.1 (BSL 1.1) + Cann-o-Call Small-Business Production Use Grant.

This document records the RC.2 license decision. The binding `LICENSE` is
release-version-neutral and applies to the source distribution that includes it.

## Finalized policy

The finalized model establishes the following terms:

- Licensor: Eric T. Sawtelle; Copyright 2026 Eric T. Sawtelle.
- Licensed Work: Cann-o-Call (the source distribution containing `LICENSE`).
- Base license: Business Source License 1.1 (BSL 1.1).
- The Additional Use Grant permits qualifying internal production use only when
  the user and its Affiliates have fewer than 50 FTE employees **and** less than
  US $5,000,000 aggregate gross annual revenue.
- An Affiliate directly or indirectly controls, is controlled by, or is under
  common control with the user; employee count and revenue are aggregated.
- The Grant excludes third-party hosted SaaS, managed services, managed
  infrastructure, paid third-party automation, resale, white-label offerings,
  and commercial services in which Cann-o-Call is material.
- A previously qualifying user has a 30-day, existing-deployment-only grace
  period to obtain a commercial license or discontinue use, with no material
  expansion or new grant-reliant deployment.
- Nonprofit and educational use remains subject to the same thresholds and
  third-party-service restrictions.
- Change Date: 2030-09-01; Change License: Apache License, Version 2.0.
- Commercial licensing contact: https://github.com/es-3581100/Cann-o-Call.

## Release rule

### Public RC/release

The public release gate requires the adopted `LICENSE`, accurate
`LICENSING.md`, `NOTICE`, and `CONTRIBUTING.md`, with no unresolved fields in
the current release documents. Before the Change Date, describe the project as
**source-available**, not OSI Open Source.

## Why this is the selected model

It provides free internal use for genuine small operators while requiring
commercial terms from enterprise-scale and commercial hosted/resale offerings,
without transferring ownership of the underlying intellectual property.
